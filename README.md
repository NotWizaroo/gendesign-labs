# Генеративный дизайн — студия

Запуск: `./start.sh` (откроется http://localhost:5500/studio/). Нужен только python3.

## Что где
- `studio/` — оболочка: сайдбар, галерея, ползунки, код, режим «Показ». Список скетчей — `studio/manifest.json`.
- `task1…5`, `lab2/` — сданные работы, не меняются. Студия открывает их как есть.
- `variants/lab1/` — новые варианты заданий лабы 1. `variants/sandbox/blank.js` — заготовка.
- `listings/lab1/`, `listings/lab2/` — **все листинги из PDF-методичек дословно** (лаба 1: 1–14, лаба 2: 1–7 и 3 фрагмента из текста). В студии они стоят внутри своего задания, с рисунком из PDF во вкладке «Описание». Данные: `listings/lab1/data/`.
- `lab1-examples/` — старые адаптированные примеры (в студии не показываются, файлы оставлены).
- `studio/refs/` — рисунки из PDF для сравнения.
- `assets/` — общие картинки (`asset('sobor.jpg')`). `libs/p5.min.js` — p5 1.9.4.

## Новый скетч
1. Скопируй `variants/sandbox/blank.js`, переименуй.
2. Добавь запись в `studio/manifest.json` (id, title, src, desc, hint, tags; `"sliders": true`, если есть params).
3. Обнови страницу студии.

## API для скетча (даёт runner)
- `const P = params({ n: {value:10, min:1, max:50, step:1, label:'Число'}, ... })` — ползунки; число, `true/false`,
  `'#rrggbb'`, строка, `options:{ 'Подпись': 'значение' }`, `{button:'Текст', fn(){...}}`.
- `pointer()` — мышь в координатах холста; пока мышь не двигали — плавный автопилот.
- `asset('имя')` — путь к файлу из `assets/`. `onParam(key, value)` — необязательный хук.
- Шрифт задавай одним именем: `textFont('Arial')`. p5 берёт его в кавычки, список через запятую не сработает.

## Листинги из методичек
- Код дословно как в PDF; отступления описаны комментарием в первой строке файла (например, `print` или обёртка в `setup()`).
- Библиотеку Generative Design (`gd.timestamp`, `gd.sortColors`, `gd.ase`, `writeFile`) заменяет прослойка в `studio/runner.js`.
- `print()` и `console.log` выводятся на экран в левом нижнем углу холста.
- Если скетчу нужны файлы данных, в манифесте есть поле `needs`; без них студия показывает подсказку, что положить и куда. Сейчас так у листинга 12 (шрифт `miso-bold.ttf` и 7 SVG, в PDF их нет).
- Заменители: `pic1–4.jpg`, `image.jpg`, `video.mp4` (10 с, собрано ffmpeg). Подставь свои под теми же именами.
