# Учебные копии для разбора кода (лаба 1)

> Запасной вариант. Основной разбор для защиты — скетчи из отчёта: `../task2…5` (задание 1 — листинг 1 из PDF). Эти копии нужны, если решим заменить что-то в отчёте.

Каждая папка — один скетч, который запускается **сам по себе**, без студии: `index.html` + `sketch.js`.
Ползунки студии заменены обычными значениями в объекте `P` вверху файла; мышь — `mouseX` / `mouseY`.

Запуск: в VS Code расширение Live Server на `index.html` нужной папки, либо `./start.sh` из корня проекта и
http://localhost:5500/study/01-albers/ (и так же для остальных).

Порядок разбора — от простого к сложному:
